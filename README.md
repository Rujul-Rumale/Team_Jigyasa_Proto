# Team Jigyasa Prototype – Deployable Buoy for Disaster Management

## Overview

Floods and cyclones often leave communities cut off, with little information about rising water levels or contamination risks. Without reliable data, rescue teams face delays and resources are wasted in guesswork. This project presents a low-cost buoy system that can be quickly deployed into affected waters. Once afloat, each buoy collects basic but vital information—such as water depth, flow, and quality—and sends it back through long-range communication. By scattering multiple buoys across an area, responders can get a real-time map of conditions, improving coordination, rescue planning, and relief distribution.

## Features

* Rapid deployment into disaster-affected waters
* Automatically floats and stabilizes
* Collects water depth, flow dynamics, temperature, and contamination data
* Transmits data through long-range networks (LoRa, mesh, satellite)
* Scalable for wide-area coverage
